# OpenSMS Backup

> A modern, open-source, privacy-first SMS backup and restore app for Android using Gmail/IMAP.

## Features

- SMS Backup
- SMS Restore
- Gmail (OAuth)
- IMAP Support
- Incremental Backup
- Material 3 UI
- No Ads
- No Tracking
- Open Source
